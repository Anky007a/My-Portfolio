03 — Leadership Playbook

Strategic quality metrics that
drive engineering speed.

Testing is not about finding bugs. It is about reducing the risk of software releases while maximizing developer velocity.

⚖️

Strict Release Gates

Every release is gated by strict, automated regression builds. Zero flaky tests allowed in the gate. This enforces codebase discipline and ensures predictable production behaviour.

Regression Locking

Any production bug must be reproduced with a dedicated automated test before a patch is shipped. This locks the regression in the build pipeline forever.

AI Quality Governance

Instructing and reviewing AI-generated code requests with the same professional rigor as standard human code blocks. If the code violates RAM ceilings, reject.

QA Workflow — How I direct the AI developer

  1. Requirement framing — I author acceptance criteria in plain English (“ratio sweep must show 0 trades made worse”).
  2. Implementation hand-off — Agent builds the test fixture / harness / endpoint.
  3. Audit — I review the diff. Signature mismatches, hot-path print() calls, and state-dict corruption patterns get rejected before merge.
  4. Pytest gate — Full suite must show 1,640 / 0 failed / ≤101 skipped.
  5. Smoke probe — Playwright screenshot + curl against /api/ops/* endpoints.
  6. Ship-dark — Env flag default OFF on first PROD deploy.
  7. Observation window — One trading session of dashboards before flipping ON.
  8. Counterfactual sign-off — A/B backtest must show net-positive across all symbols.
  9. Live verification — Post-flip curl on /api/ops/hardlock-config confirms PROD env picked up the change.

Real Pushback Examples — Rejected Merges in this Release

Four separate AI-generated code suggestions were rejected before they touched production:

  • “Sensex whipsaw filter” snippet — used a one-sided OBI scale when the codebase uses signed [-1, +1]. Would have biased the bot bullish-only on SENSEX. Replaced with a 1-line .env tighten.
  • “Zero-allocation NumPy pipeline” rewrite — mathematically disproved (existing Python dict path is 2,615× faster than the latency budget). Replaced with WS-sync OBI fast-path + REST circuit breaker.
  • “Virtual tick replay engine” — wrong function signature on evaluate_obi_exhaustion (would have TypeError'd on the first call), print() in a hot replay loop, and corrupted PER_SYMBOL_STATE. Replaced with decision-snapshot A/B harness.
  • State-dict regression caught post-merge — OBI hot-path stored its running-flag inside PER_SYMBOL_STATE, crashing the safety loop with 'bool' object has no attribute 'get'. Caught in 4 minutes via supervisor log tail; fixed by moving to module-level state.
