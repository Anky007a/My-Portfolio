05 — Debugging Examples

Root-cause tracking on
the independent project.

A sample of issues I found and fixed while testing the personal trading project — traced to their root cause and locked into the automated test suite.

Defect Category Symptom Profile Root Cause Fix & Regression Lock
API Rate Limit HTTP 429 Blocks & 1000ms stale lag during high-volatility market opens. REST polling (`/marketfeed/quote`) every 1s hammered endpoint loops with ~3,600 calls/hour. Migrated entire market depth logic to a push-based WebSocket system, reducing REST polling dependencies to near-zero.
Math Freeze Trailing stops frozen during flat price gaps; stop-losses failed to adjust or execute. True Range ($TR$) dropped to zero in stagnant fields, shrinking Wilder's RMA ATR calculation to near-zero. Implemented strict minimum floor constraints directly into the engine, clamping index steps (NIFTY: 5.0, BANKNIFTY: 12.0, SENSEX: 16.0).
Order Collision Infinite loop of failed sell orders and server database clutter on Intraday configurations. Manual app trades registered as MIS successfully synced, but exit payloads were hardcoded to MARGIN. Reconfigured sync arrays to parse, store, and dynamically match exact position product types during routing execution.
Leakage Logic Small, low-conviction breakout trades hit targets but consistently drained net capital scales. Omission of round-trip transaction elements (brokerage, STT, exchange fees, stamp duties, GST) from exit models. Engineered a fee-aware gate that checks expected premium swings and halts entries if margin targets fall below 4x round-trip fees.
Data Sync Lag Silent websocket freezes leading to trade operations running against stale, out-of-date price vectors. Broker connections dropped quietly without throwing network exceptions, avoiding standard catch conditions. Built a heartbeat watchdog tracking tick deltas; aborts entry if lags hit 5s and drops/rebuilds socket in under 5s.
Global Scope Leak BANKNIFTY and SENSEX execution lanes completely silent; required massive point shifts to trigger. Global parameters intended strictly for NIFTY leaked into all multi-index tracking instances. Isolated instance parameters inside the engine to protect independent index baseline parameters.
Index Whipsaw Instant trade failure on call entries due to index pull contradictions. Lack of index velocity tracking across correlated market components during volatile breakout sprints. Added a cross-index flow gate tracking 30s futures velocity thresholds to drop entries if opposing sectors slip past 0.15%.

07 — Principles I Work By

How I run QA for
stable, on-time delivery.

Testing works best when it's built into the process early, not bolted on at the end.

I / Shift-Left

Catch Issues Early

QA engineers join early product and design reviews. Catching behavioral gaps before code is written is far cheaper than fixing them after.

II / Environment Parity

Realistic Staging

Staging environments use anonymized, production-like data at scale, so builds are tested against realistic conditions before release.

III / Developer Velocity

Fast Feedback Loops

If a full regression run takes too long, developers stop trusting it. I focus on parallelism and targeted execution to keep feedback fast.
